# Plan de Trabajo - Proyecto Portfolio Rebeca

Este documento detalla la planificación y el proceso de ejecución seguido para el desarrollo de la plataforma, dividida en cinco fases críticas de ingeniería web.

## Fase 1: Conceptualización y Diseño (Semana 1)

- [x] Definición del Stack Tecnológico: Bootstrap 5 + GSAP (Nivel 2).
- [x] Diseño del Sistema de Identidad: Selección de paleta cromática (Dark Mode) y tipografías (Inter & Playfair Display).
- [x] Arquitectura de Información: Definición de secciones (Hero, About, Projects, Contact).
- [x] Establecimiento de la estructura de carpetas profesional (`assets/`, `docs/`, `data/`).

## Fase 2: Estructura y Maquetación (Semana 2)

- [x] Desarrollo del HTML5 semántico utilizando etiquetas de sección (`main`, `section`, `article`).
- [x] Implementación de Grid System de Bootstrap para asegurar el diseño responsive.
- [x] Creación de componentes tipo "Pill" para la navegación avanzada.
- [x] Desarrollo de la página de error 404 personalizada con branding coherente.

## Fase 3: Estética y Glassmorphism (Semana 2-3)

- [x] Configuración de variables CSS globales (Design Tokens).
- [x] Implementación de efectos de desenfoque de fondo (`backdrop-filter`) y bordes semitransparentes.
- [x] Estilización de formularios compactos y componentes de interfaz.
- [x] Optimización de accesibilidad (contrastes y jerarquía visual).

## Fase 4: Interactividad y Animaciones GSAP (Semana 3)

- [x] Registro y configuración de plugins (ScrollTrigger).
- [x] Desarrollo del "Visual Engine" para el fondo dinámico del Hero (Parallax).
- [x] Implementación de animaciones de revelado (`gsap-reveal`) para el contenido al hacer scroll.
- [x] Animación de micro-interacciones en barras de progreso y tarjetas de proyectos.
- [x] Programación del cierre automático del menú responsive mediante la API de Bootstrap.

## Fase 5: Documentación y Despliegue (Semana 4)

- [x] Redacción del `README.md` con sección obligatoria de uso de IA.
- [x] Completado del `Project Brief` y `Plan de Trabajo`.
- [x] Selección de Licencia MIT para el repositorio.
- [x] Despliegue final en GitHub Pages y validación de errores en consola.
