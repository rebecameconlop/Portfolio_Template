# Project Inspiration

## Trends

### 1. Glassmorphism & Depth

Uso de efectos de desenfoque de fondo (`backdrop-filter`) y bordes sutiles para crear una jerarquía visual basada en capas. Esta tendencia permite que la interfaz se sienta ligera y moderna, manteniendo la legibilidad sobre fondos dinámicos.

### 2. Bento Grid Layout

Inspiración en la organización de secciones mediante contenedores modulares con bordes redondeados (como se ve en la sección de proyectos), permitiendo que el contenido sea adaptable y fácil de escanear visualmente.

### 3. Kinetic Typography & Micro-interactions

Integración de GSAP para dar vida a la tipografía y a los elementos de la interfaz. La tendencia se centra en que el movimiento no sea solo decorativo, sino que guíe la atención del usuario hacia los puntos de conversión (CTA).

## Theme Draft

### Project Core Concept

**Aurion** es un ecosistema visual diseñado para desarrolladores y creativos que buscan una presencia digital sofisticada. El concepto central es la **"Transparencia Técnica"**: utilizar elementos visuales cristalinos para mostrar un código limpio y una estructura organizada.

No es solo un portfolio, sino una herramienta de branding personal que equilibra la potencia de un framework robusto (Bootstrap) con la delicadeza de animaciones cinemáticas (GSAP), eliminando cualquier ruido visual para centrarse en la calidad del trabajo expuesto.
