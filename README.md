## 🚀 Tecnologías Utilizadas

- **HTML5 & CSS3**: Estructura semántica y diseño basado en variables (Design Tokens).
- **Bootstrap 5.3**: Framework para la maquetación responsive y componentes de interfaz.
- **GSAP 3.12**: Motor de animaciones para efectos de scroll, parallax y revelado de contenido.
- **Glassmorphism**: Estética visual basada en transparencias y desenfoques profundos.

## 🛠️ Estructura del Proyecto

```text
/
├── assets/
│   ├── css/          # Hojas de estilo organizadas (layout, components, index)
│   ├── js/           # Lógica de animaciones (main.js)
│   └── img/          # Recursos visuales
├── data/             # Metadatos del proyecto (project.yaml)
├── docs/             # Documentación técnica (brief, plan, inspiration)
├── index.html        # Página principal
└── 404.html          # Página de error personalizada
```
