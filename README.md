## Concepto del Proyecto

Este portfolio es una plataforma de alto rendimiento visual diseñada bajo la estética **Glassmorphism**. El objetivo es proyectar una identidad técnica y creativa, equilibrando la robustez de **Bootstrap 5** con la fluidez cinematográfica de **GSAP**.

## Tecnologías Utilizadas

- **HTML5 & CSS3**: Estructura semántica avanzada y diseño basado en Design Tokens (Variables CSS).
- **Bootstrap 5.3**: Framework para maquetación responsive y componentes UI personalizados.
- **GSAP 3.12**: Motor de animaciones para efectos de scroll, parallax y micro-interacciones.
- **Google Fonts**: Implementación de tipografía dual (Inter para lectura y Playfair Display para acentos).
